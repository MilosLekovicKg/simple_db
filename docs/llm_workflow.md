# LLM collaboration workflow

Use this workflow to keep the project productive and educational:

- Ask for one feature at a time.
- Require a regression test before accepting a behavior change.
- Prefer small patches over large rewrites.
- Ask the model to explain the trade-offs of each design decision.
- Keep a note of what changed and why.

Suggested prompt template:

> Implement the next small feature for this database project. Keep the change minimal, add or update tests, and explain the design trade-off clearly.
